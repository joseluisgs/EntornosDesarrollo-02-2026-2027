## 1. Introducción

> 💡 **Punto de partida:** Elegir un IDE no es algo trivial. Depende del lenguaje, del tipo de proyecto, del presupuesto, del equipo y de tu experiencia. En esta actividad de evaluación vas a analizar cuatro escenarios reales y justificar qué IDE elegirías para cada uno.

### 1.1. Objetivos

- Analizar escenarios reales de desarrollo de software.
- Evaluar IDEs usando una rúbrica objetiva.
- Justificar por escrito la decisión tomada.
- Exponer oralmente la decisión al profesor.

### 1.2. Requisitos previos

- Haber completado las prácticas 1-6.
- Conocer las características principales de IntelliJ, Rider y VS Code.
- Acceso a internet para investigar datos actualizados.

---

## 2. Enunciado de la actividad

**Instrucciones generales:**

1. Lee atentamente cada escenario.
2. Para cada escenario, evalúa al menos 3 IDEs usando la rúbrica de la sección 4.
3. Puntúa cada IDE según los criterios de la tabla.
4. Justifica por escrito (mínimo 200 palabras por escenario) qué IDE elegirías y por qué.
5. Prepara una exposición oral de 5 minutos por escenario.

> ⚠️ **Advertencia:** No basta con decir "elegiría X porque es el mejor". Debes justificar con datos objetivos: coste, rendimiento, extensibilidad, soporte de lenguajes, etc.

## 3. Escenarios

### 3.1. Escenario A: Estudiante que empieza en programación

**Contexto:**
- Tienes 16 años y nunca has programado.
- Tienes un portátil con 8 GB de RAM y 256 GB de SSD.
- No quieres gastar dinero en software.
- Tu profesor usa Java en clase.
- Quieres aprender a programar sin complicaciones.

**IDEs a evaluar:**
- IntelliJ IDEA Community
- VS Code
- BlueJ (alternativa para principiantes)

**Preguntas guía:**
- ¿Cuál es más fácil de usar para un principiante?
- ¿Cuál consume menos recursos?
- ¿Cuál tiene más tutoriales y documentación para empezar?
- ¿El coste es un factor determinante?

> 💡 **Consejo:** Para un principiante, la facilidad de uso y la disponibilidad de tutoriales pueden ser más importantes que las funcionalidades avanzadas.

### 3.2. Escenario B: Desarrollador backend Java en empresa grande

**Contexto:**
- Tienes 5 años de experiencia como desarrollador Java.
- Trabajas en una empresa de banca con proyectos legacy (Java 8) y nuevos (Java 17+).
- La empresa te paga la licencia si la necesitas.
- Usas Spring Boot, Hibernate, Maven y mucho SQL.
- Necesitas depuración remota y profiling.

**IDEs a evaluar:**
- IntelliJ IDEA Ultimate
- Eclipse
- VS Code con extensiones Java

**Preguntas guía:**
- ¿Cuál tiene mejor soporte para Spring Boot?
- ¿Cuál maneja mejor proyectos grandes?
- ¿Vale la pena pagar la licencia de Ultimate?
- ¿Eclipse sigue siendo viable en 2026?

### 3.3. Escenario C: Desarrollador web full-stack freelance

**Contexto:**
- Trabajas por tu cuenta haciendo páginas web para pequeñas empresas.
- Usas HTML, CSS, JavaScript (React), PHP y bases de datos MySQL.
- Tienes poco presupuesto para herramientas.
- Necesitas flexibilidad y rapidez.
- A veces trabajas desde diferentes ordenadores.

**IDEs a evaluar:**
- VS Code
- PhpStorm
- WebStorm

**Preguntas guía:**
- ¿VS Code puede cubrir todas tus necesidades con extensiones?
- ¿Vale la pena pagar por PhpStorm o WebStorm?
- ¿Qué IDE es más rápido para desarrollo web?
- ¿Cómo afecta el trabajo remoto a la elección?

### 3.4. Escenario D: Equipo de 5 desarrolladores C# en startup

**Contexto:**
- Sois 5 desarrolladores en una startup que crea una API REST con .NET 8.
- Usáis Git, GitHub Actions y Docker.
- El presupuesto es limitado pero pueden invertir en herramientas.
- Necesitáis un IDE potente para C# que facilite la colaboración.
- Trabajáis en Windows y macOS.

**IDEs a evaluar:**
- JetBrains Rider
- Visual Studio 2022 Community
- VS Code con C# Dev Kit

**Preguntas guía:**
- ¿Visual Studio Community es suficiente para un equipo?
- ¿Rider vale la pena para C#?
- ¿VS Code puede manejar un proyecto .NET complejo?
- ¿Qué IDE se integra mejor con Docker y CI/CD?

## 4. Formato de entrega

### Documento escrito (PDF)

El informe debe contener:

1. **Portada** con nombre, apellido, fecha y título de la actividad.
2. **Índice** de contenidos.
3. **Análisis de cada escenario:**
   - Descripción del escenario.
   - Tabla de puntuación de los 3 IDEs.
   - Justificación escrita (mínimo 200 palabras).
   - IDE elegido y por qué.
4. **Conclusiones generales:** Reflexión sobre qué aprendiste.

### Exposición oral (5 minutos)

Estructura sugerida:

1. **Introducción** (30 segundos): Presenta el escenario.
2. **Análisis** (2 minutos): Resume la comparación de IDEs.
3. **Decisión** (1 minuto): Anuncia qué IDE elegirías y la razón principal.
4. **Reflexión** (30 segundos): ¿Qué has aprendido con esta actividad?

> 💡 **Consejo:** Practica tu exposición antes de presentarla. Sé conciso y ve al grano. Los profesores valoramos la claridad y los argumentos sólidos.
